# Plan 3 — LiftUI (native macOS app) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Lift.app, the native SwiftUI front end over LiftCore and LiftServer. It covers:
- the screens: sidebar (Generate, Queue, History, Models, Settings) and the result viewers;
- the first-launch wizard;
- the interrupted-jobs sheet;
- the menu bar extra;
- macOS notifications;
- launch at login and keep running in the menu bar.

It is built reproducibly, launches, and passes a launch smoke test in CI.

**Architecture:** The Swift package gets a `LiftUI` library target with one file per screen plus `@MainActor @Observable` view models. Those models run without UI and are tested with Swift Testing.
- `AppModel` owns the in-process `Lift` actor and the `LiftServer`, and mirrors the queue, resources, models and settings once a second.
- Every action is a `Lift` or `LiftServer` command. Risky ones go through `AppModel.gated`, which shows LiftCore's own impact text and runs the command again with `confirm: true` on OK.
- Lift.app is a thin XcodeGen project (`App/project.yml`): the `@main` App, the menu bar scene, the app delegate, and a `lift-mcp` tool target copied into `Contents/MacOS`.
- A build phase copies `dev-recipes/` and `lift_worker` into `Contents/Resources`.

**Tech Stack:**
- Swift 6.3.3, Xcode 26.6, macOS 26, SwiftUI and Observation.
- GLTFKit2 0.5.15 (SceneKit) for the 3D preview, plus SceneKit/ModelIO for OBJ and USDZ.
- AVKit for video and audio.
- UserNotifications, ServiceManagement (`SMAppService`) and `MenuBarExtra`.
- XcodeGen 2.45+ to generate the Xcode project.
- Swift Testing.

## Global Constraints

- Platform and language:
  - macOS 26+ on Apple Silicon.
  - Swift 6 language mode with strict concurrency: `SWIFT_VERSION: "6.0"` in the app, `// swift-tools-version: 6.2` in the package.
  - Built with Xcode 26.6 / Swift 6.3.3.
- Packages: add exactly one, `https://github.com/warrenm/GLTFKit2` `exact: "0.5.15"`, a binary xcframework (dynamic) that Xcode embeds in `Contents/Frameworks`. Commit `Package.resolved`. XcodeGen is a build tool, not a dependency.
- Tests:
  - Swift tests use Swift Testing (`import Testing`, `@Test`, `#expect`, `#require`), never XCTest.
  - No XCUITest: UI testing needs a one-time interactive automation approval (`Authentication canceled. System authentication is running.`). The app is checked by the launch smoke test (`App/smoke-test.sh`).
- Code structure:
  - SwiftUI with Observation.
  - View models are `@MainActor @Observable` classes in `LiftUI` and are testable without UI.
  - Views are split by screen, one file each.
- Principle 3 (one command layer): the UI calls only `Lift` and `LiftServer` methods. It never writes the database. It reads only two files: `jobs/<id>/log.txt` (live log) and `models/<id>/install.log`.
- Principle 2 (Lift executes, the caller decides):
  - The app never picks a recipe, settings or an order for the user: no preselected project, no routing of files by type, no "warm model" hints or toggles.
  - The Queue shows LiftCore's order (priority, then position, then submission).
  - Wait reasons, memory and status are shown as facts.
  - The mockup's "Warm model first" switch, "Starts next · model warm" notes and "Retry with Low memory mode" button are left out on purpose.
- Every confirm-gated command goes through `AppModel.gated(_:then:)`. The dialog shows LiftCore's `confirmationRequired` text verbatim, and nothing changes before OK.
- Weights are downloaded only by an explicit Install or Download weights, each confirmed. Uninstall never deletes weights (Plan 1 rule), so the UI has no such option.
- **User rules:**
  - No weight downloads and no prerequisite installs during development or tests.
  - Tests use temp workdirs, `MemorySecretStore` and the in-memory `MemoryPrefs`. They never write the user's defaults or Keychain.
  - The smoke test writes only inside its `mktemp -d` folder: `-workdir` and `-setupDone` arrive on the command line, and `CFFIXED_USER_HOME` redirects AppKit's own preference writes.
  - Nothing outside Lift's own files is deleted. `AppModel.installRuntime` replaces only `<workdir>/runtime/lift_worker`, and the workdir move moves the folder, after confirmation.
- Signing: a personal build, ad-hoc signed (`CODE_SIGN_IDENTITY: "-"`), no team, no App Sandbox (`com.apple.security.app-sandbox: false`), no hardened runtime.
- Local build flags. Use them in every local command; CI doesn't need the first two.
  - `swift build`/`swift test` take `--disable-keychain`, and `xcodebuild` takes `-packageAuthorizationProvider netrc`. Without them, SwiftPM's download of the GLTFKit2 binary hangs in a Keychain lookup that can't prompt.
  - `xcodebuild` takes `-skipPackagePluginValidation` for LiftServer's OpenAPI generator plugin.
- Git:
  - Work on branch `oshricohenme/7jtm2` and don't push.
  - Commit with explicit paths: `git add <paths> && git commit -m "<message>" -m "Claude-Session: https://claude.ai/code/session_01YQaNtMcUoMHe2knND64orw" -- <paths>`.

## Decisions to fold into the spec

1. **Wizard order (§11):** working directory → toolchain → recipes → Hugging Face token → MCP snippet. The workdir comes first because opening it starts the engine. The engine runs the toolchain checks and installs, copies the bundled recipes and stores the token.
2. **Export UI moves to Plan 4**, with the Exporter and its `export_dir`/`export_formats`/`cleanup_after_export` settings. That covers Generate's export section, the wizard's export folder and cleanup default, and Settings' export rows.
3. **App settings are LiftCore settings:**
   - `notifications` (default true), `launch_at_login` (false) and `menu_bar` (true) are `settings_set` keys, so HTTP and MCP can change them too.
   - The app follows them. For `launch_at_login` it reconciles with `SMAppService.mainApp` once a second. If the system refuses (an ad-hoc build can be refused), it shows an alert and writes the system's actual state back, so it doesn't retry every second.
4. **Where the app keeps what lives outside the workdir:** the workdir path and "setup done" are in `UserDefaults` (`workdir`, `setupDone`), because the database lives inside the workdir.
5. **Moving the working directory is app-level:**
   - The UI only: Settings → Storage → Move…. LiftCore can't reopen itself, so there's no HTTP/MCP command for it in v1.
   - It asks for confirmation, stops the engine and server, moves the folder, and reopens there.
   - The confirmation text warns that installed models may need Reinstall when their venv has absolute paths.
6. **Worker runtime:** `lift_worker` is copied from the bundle to `<workdir>/runtime/` on every launch, and `LiftConfig.workerRuntime` points there. That way Python's bytecode cache never writes into the signed app bundle.
7. **Result viewers by file extension:**
   - glTF goes through GLTFKit2; OBJ and USDZ go through SceneKit/ModelIO. Modes are Textured, Clay (materials swapped on load), Wireframe and Skeleton (SceneKit debug options), plus Play animation when the glTF has animations.
   - FBX has no preview (Reveal in Finder).
   - The mockup's "Open in Blender" is dropped (it's not in the spec).
   - Video and audio use AVKit's `VideoPlayer`.
8. **History** lists finished jobs (succeeded, failed, cancelled). **Queue** lists unfinished ones, including interrupted. Filters:
   - All, 3D, Image, Video and Audio map to `JobFilter.modality`.
   - Failed maps to `states: [.failed]`.
   - Rigged keeps jobs whose last task outputs `rigged_mesh`.
9. **Options are read-only in Models.** The mockup's "Your default" column and Generate's "Save as default" aren't in the spec, so they're left out. Every job sends the form's values, which start at the recipe defaults.
10. **Copy as curl** rebuilds `POST /v1/jobs` (Plan 2's JSON body: steps, title, priority) from the job's stored steps. It uses the job's copied inputs and leaves out a chained step's first input.
11. **The smoke test replaces XCUITest** (see Global Constraints): `-LiftSmokeTest YES` makes the app print `LIFT_SMOKE sidebar: …` once the sidebar is on screen, then quit.
12. **XcodeGen** (`App/project.yml`) is the one Xcode project. It's needed for a real bundle (Info.plist, entitlements, notifications, login item), for embedding GLTFKit2 and for the `lift-mcp` tool. The `.xcodeproj` is generated and git-ignored. `Package.swift` gains a `MCPBridge` library product so the tool target can link it.

## Review Focus

1. **The app quits or crashes while a job runs.** On the next launch the interrupted sheet lists the job. Re-queue restarts it from that step, and Decide Later leaves it. Pinned by `interruptedJobsAreOfferedOnLaunch` (Task 3).
2. **A risky button anywhere** (cancel running, delete, install, uninstall, force start, unload busy, LAN, rotate, install tools, move workdir) must change nothing until the user says OK. Pinned by `gatedCommandsAskFirstAndRunOnConfirm` and by `movingTheWorkdirTakesItsDataAlong`, which checks that the folder is untouched before OK (Task 3).
3. **Dropped files that don't fit the chosen task** (a mesh on Image → 3D, a folder, the same file twice, an upper-case extension) are ignored, never queued, and give one job per remaining file. Pinned by `oneRequestPerFileWithTheFollowUpStep` (Task 2).
4. **An out-of-range option value** shows its error next to the field, keeps the dropped files, and queues nothing. Pinned by `submitQueuesAndKeepsFieldErrorsInTheForm` (Task 3).
5. **Launch at login changed over HTTP/MCP, or refused by the system** (ad-hoc build). The app follows the setting. If the system refuses, the user sees an alert and the setting goes back to the system's state, with no retry every second. Pinned by `launchAtLoginFollowsTheSetting` (Task 3).

    public func resourcesResetEstimates(recipe: String? = nil) throws -> ResourcesView {
        try store.db.write { db in
            if let recipe {
                try db.execute(sql: "DELETE FROM memorySample WHERE recipe = ?", arguments: [recipe])

                try db.execute(sql: "DELETE FROM memorySample")
            }
        }

    }

    /// A small file to drop or submit.
    static func file(_ name: String) throws -> URL {
        let url = try tempDir().appending(path: name)
        try Data([0x89, 0x50, 0x4E, 0x47]).write(to: url)
        return url
    }

    /// A Lift on a temp workdir with the developer recipes (the Test Cube) shown. Nothing is installed.
    static func lift() async throws -> Lift {
        let lift = try await Lift.open(LiftConfig(workdir: try tempDir(), workerRuntime: workerSource,
                                                  bundledRecipes: bundledRecipes, housekeepingInterval: .seconds(3600),
                                                  hfHub: try tempDir()))
        _ = try await lift.settingsSet("dev_recipes", .bool(true))
        return lift
    }
}

/// Polls `condition` every 50 ms for up to `seconds`.
@MainActor func eventually(_ seconds: Double = 10, _ condition: @MainActor () async throws -> Bool) async throws -> Bool {
    let end = ContinuousClock.now + .seconds(seconds)
    while ContinuousClock.now < end {
        if try await condition() { return true }
        try await Task.sleep(for: .milliseconds(50))
    }
    return false
}

/// Display text for LiftCore values. Facts only, no advice (spec principle 2).
public enum Format {

    }

    public static func gb(_ n: Int) -> String {

    }

    public static func waitReason(_ r: WaitReason?) -> String {
        switch r {
        case nil: "Queued"
        case .noFreeSlot: "Waiting for a free slot"
        case .memory(let needed, let free): "Needs \(gb(needed)), \(gb(free)) free"
        case .modelInstalling: "Model is installing"
        case .modelNotInstalled: "Model not installed"
        case .modelUnsupported: "Model unsupported on this Mac"
        case .weightsUnverified: "Weights not verified"
        case .queuePaused: "Queue paused"
        }
    }

    public static func state(_ s: JobState) -> String {
        s.rawValue.prefix(1).uppercased() + s.rawValue.dropFirst()
    }

    public static func status(_ s: ModelStatus) -> String {
        switch s {
        case .notInstalled: "Not installed"
        case .installing(let phase): phase.prefix(1).uppercased() + phase.dropFirst() + "…"
        case .installed: "Installed"
        case .updateAvailable: "Update available"
        case .installFailed: "Install failed"
        case .unsupported: "Unsupported"
        case .weightsMissing: "Weights missing"
        case .weightsCorrupt: "Weights corrupt"

import Foundation
import LiftCore
import Observation

/// A task's shape, used to group the same kind of task across recipes into one chip.
public struct TaskKind: Hashable, Sendable {
    public var inputs: [IOType]
    public var output: IOType

    public var label: String {
        inputs.map { Format.io($0) }.joined(separator: " + ") + " → " + Format.io(output, asOutput: true)
    }
}

/// One recipe task, addressed the way a step names it.
public struct TaskRef: Hashable, Sendable {
    public var recipe: String
    public var task: String
}

public struct TaskChip: Identifiable, Sendable {
    public var kind: TaskKind
    /// Recipes offering it, in catalog order.
    public var models: [ModelView]
    public var id: TaskKind { kind }
}

/// Generate screen state: modality → task chip → recipe → settings → inputs, plus an optional
/// follow-up step, priority and export options. It builds requests; the user decides everything.
@MainActor @Observable
public final class GenerateModel {
    public nonisolated static let modalities = [("3d", "3D"), ("image", "Image"), ("video", "Video"), ("audio", "Audio")]

    public var models: [ModelView] = [] {
        didSet { reconcile() }
    }
    public var modality = "3d" {
        didSet { if modality != oldValue { kind = nil; reconcile() } }
    }
    public var kind: TaskKind? {
        didSet { if kind != oldValue { recipe = nil; reconcile() } }
    }
    public var recipe: String? {
        didSet { if recipe != oldValue { values = defaults(for: current) } }
    }
    public var values: [String: SettingValue] = [:]
    /// Files for the task's first input, one job per file.
    public var files: [URL] = []
    /// Text for a first input of type `text`, and fixed values for inputs after the first.
    public var text = ""
    public var otherInputs: [String: String] = [:]
    public var then: TaskRef? {
        didSet { if then != oldValue { thenValues = defaults(for: then) } }
    }
    public var thenValues: [String: SettingValue] = [:]
    public var priority: Priority = .normal
    public var errors: [FieldError] = []

    public init() {}

    // MARK: derived

    public func taskCount(_ modality: String) -> Int { chips(modality).count }

    public func chips(_ modality: String) -> [TaskChip] {
        var order: [TaskKind] = []
        var byKind: [TaskKind: [ModelView]] = [:]
        for m in models {
            for t in m.recipe.tasks where t.modality == modality {
                let k = TaskKind(inputs: t.inputs.map(\.type), output: t.output)
                if byKind[k] == nil { order.append(k) }
                if byKind[k]?.contains(where: { $0.id == m.id }) != true { byKind[k, default: []].append(m) }
            }
        }
        return order.map { TaskChip(kind: $0, models: byKind[$0] ?? []) }
    }

    /// The selected recipe task.
    public var current: TaskRef? {
        guard let kind, let recipe, let m = models.first(where: { $0.id == recipe }),
              let t = m.recipe.tasks.first(where: { TaskKind(inputs: $0.inputs.map(\.type), output: $0.output) == kind && $0.modality == modality })
        else { return nil }
        return TaskRef(recipe: m.id, task: t.id)
    }

    public func task(_ ref: TaskRef?) -> RecipeTask? {
        guard let ref else { return nil }
        return models.first { $0.id == ref.recipe }?.recipe.task(ref.task)
    }

    /// Tasks (any recipe, any modality) whose first input accepts the current task's output.
    public var followUps: [TaskRef] {
        guard let output = task(current)?.output else { return [] }
        return models.filter { !$0.isUnsupported }.flatMap { m in
            m.recipe.tasks.filter { $0.inputs.first?.type.accepts(output) == true }.map { TaskRef(recipe: m.id, task: $0.id) }
        }
    }

    /// One request per file (or one for a text first input).
    public var requests: [SubmitRequest] {
        guard let ref = current, let task = task(ref), let first = task.inputs.first else { return [] }
        let firsts: [String] = first.type == .text ? (text.isEmpty ? [] : [text]) : files.map(\.path)
        return firsts.map { value in
            var inputs = otherInputs.filter { k, _ in task.inputs.dropFirst().contains { $0.name == k } }
            inputs[first.name] = value
            var steps = [StepRequest(recipe: ref.recipe, task: ref.task, inputs: inputs, settings: values)]
            if let then { steps.append(StepRequest(recipe: then.recipe, task: then.task, settings: thenValues)) }
            return SubmitRequest(steps: steps, priority: priority, source: .ui)
        }
    }

    public func errors(forSetting key: String, step: Int) -> [String] {
        errors.filter { $0.field == "steps[\(step)].settings.\(key)" }.map(\.message)
    }

    // MARK: changes

    /// The first input's type, which decides what the drop zone takes.
    public var firstInput: TaskInput? { task(current)?.inputs.first }

    /// Adds dropped or chosen files that fit the first input (folders for `image_set`); returns how many.
    @discardableResult
    public func add(_ urls: [URL]) -> Int {
        guard let type = firstInput?.type else { return 0 }
        let before = files.count
        for url in urls where !files.contains(url) {
            let isDir = (try? url.resourceValues(forKeys: [.isDirectoryKey]).isDirectory) ?? false
            if type == .imageSet ? isDir : !isDir && type.fileExtensions.contains(url.pathExtension.lowercased()) { files.append(url) }
        }
        return files.count - before
    }

    /// Prefills the form to use `path` (an output) as the input of `ref` ("Use as input for…").
    public func use(_ path: String, for ref: TaskRef) {
        guard let m = models.first(where: { $0.id == ref.recipe }), let t = m.recipe.task(ref.task) else { return }
        modality = t.modality
        kind = TaskKind(inputs: t.inputs.map(\.type), output: t.output)
        recipe = ref.recipe
        files = [URL(filePath: path)]
    }

    func defaults(for ref: TaskRef?) -> [String: SettingValue] {
        var out: [String: SettingValue] = [:]
        for def in task(ref)?.settings ?? [] { out[def.key] = def.default }
        return out
    }

    /// Keeps the selection valid after the model list or modality changes. The first chip is shown
    /// (navigation only); a recipe is never picked for the user (spec principle 2).
    func reconcile() {
        let chips = chips(modality)
        if kind == nil || !chips.contains(where: { $0.kind == kind }) { kind = chips.first?.kind }
        let offered = chips.first { $0.kind == kind }?.models ?? []
        if let recipe, !offered.contains(where: { $0.id == recipe && !$0.isUnsupported }) { self.recipe = nil }
        if let then, !followUps.contains(then) { self.then = nil }
    }
}

public extension ModelView {
    var isUnsupported: Bool {
        if case .unsupported = status { true } else { false }
    }
    var isInstalled: Bool {
        switch status {
        case .installed, .updateAvailable: true
        default: false
        }
    }
}

import LiftCore
import SwiftUI

/// The options form a recipe task's settings schema generates (spec §4): one control per setting,
/// `basic` ones first and the rest under "Advanced". Edits `values`; validation is LiftCore's.
struct SettingsForm: View {
    let defs: [SettingDef]
    @Binding var values: [String: SettingValue]
    let errors: (String) -> [String]
    @State private var advanced = false

    init(defs: [SettingDef], values: Binding<[String: SettingValue]>, errors: @escaping (String) -> [String] = { _ in [] }) {
        self.defs = defs
        _values = values
        self.errors = errors
    }

    var body: some View {
        let basic = defs.filter { ($0.group ?? "basic") == "basic" }
        let rest = defs.filter { ($0.group ?? "basic") != "basic" }
        ForEach(basic, id: \.key) { row($0) }
        if !rest.isEmpty {
            DisclosureGroup("Advanced", isExpanded: $advanced) {
                ForEach(rest, id: \.key) { row($0) }
            }
        }
    }

    func row(_ def: SettingDef) -> some View {
        VStack(alignment: .leading, spacing: 2) {
            control(def)
            if let help = def.help { Text(help).font(.caption).foregroundStyle(.secondary) }
            ForEach(errors(def.key), id: \.self) { Text($0).font(.caption).foregroundStyle(.red) }
        }
    }

    @ViewBuilder func control(_ def: SettingDef) -> some View {
        switch def.type {
        case .bool:
            Toggle(def.label, isOn: Binding(get: { values[def.key] == .bool(true) }, set: { values[def.key] = .bool($0) }))
        case .int:
            TextField(def.label, value: Binding(get: { Int(values[def.key]?.description ?? "") ?? 0 }, set: { values[def.key] = .int($0) }),
                      format: .number.grouping(.never))
        case .float:
            TextField(def.label, value: Binding(get: { Double(values[def.key]?.description ?? "") ?? 0 }, set: { values[def.key] = .float($0) }),
                      format: .number.grouping(.never))
        case .enum:
            let options = def.options ?? []
            let picker = Picker(def.label, selection: Binding(get: { values[def.key] ?? options.first ?? .string("") }, set: { values[def.key] = $0 })) {
                ForEach(options, id: \.self) { Text($0.description).tag($0) }
            }
            if options.count <= 4 { picker.pickerStyle(.segmented) } else { picker.pickerStyle(.menu) }
        case .string, .path:
            TextField(def.label, text: Binding(get: { values[def.key]?.description ?? "" }, set: { values[def.key] = .string($0) }))
        }
    }
}

import Foundation
import LiftCore
import LiftServer
import Observation

/// Where Lift.app keeps what it ships: `Contents/Resources/dev-recipes`, `Contents/Resources/lift_worker`
/// and `Contents/MacOS/lift-mcp`.
public struct AppPaths: Sendable {
    public var bundledRecipes: URL
    /// The folder holding the `lift_worker` package.
    public var workerSource: URL
    public var bridge: URL?

    public init(bundledRecipes: URL, workerSource: URL, bridge: URL?) {
        self.bundledRecipes = bundledRecipes
        self.workerSource = workerSource
        self.bridge = bridge
    }

    public static var main: AppPaths {
        let resources = Bundle.main.resourceURL ?? Bundle.main.bundleURL
        let bridge = Bundle.main.bundleURL.appending(path: "Contents/MacOS/lift-mcp")
        return AppPaths(bundledRecipes: resources.appending(path: "dev-recipes"), workerSource: resources,
                        bridge: FileManager.default.isExecutableFile(atPath: bridge.path) ? bridge : nil)
    }
}

public enum AppSection: String, CaseIterable, Identifiable, Sendable {
    case generate, queue, history, models, settings
    public var id: String { rawValue }
    public var title: String { rawValue.prefix(1).uppercased() + rawValue.dropFirst() }
    public var symbol: String {
        switch self {
        case .generate: "square.and.arrow.up"
        case .queue: "list.bullet"
        case .history: "square.grid.2x2"
        case .models: "shippingbox"
        case .settings: "gearshape"
        }
    }
}

/// The two values the app keeps outside the workdir: which workdir, and whether the wizard finished.
/// `UserDefaults` in the app; a dictionary in tests, so they never write the user's preferences.
public protocol PreferenceStore: AnyObject {
    func string(forKey key: String) -> String?
    func bool(forKey key: String) -> Bool
    func set(_ value: Any?, forKey key: String)
}

extension UserDefaults: PreferenceStore {}

/// A risky command waiting for the user's OK: `message` is the command's own impact text.
public struct Confirmation: Identifiable {
    public let id = UUID()
    public let message: String
    let run: @MainActor () async -> Void

    @MainActor public func confirm() async { await run() }
}

/// Something a notification reports (spec §8, §11).
public enum JobEvent: Equatable, Sendable {
    case finished(JobView)
    case waitingForMemory(JobView)
}

/// The app's state: owns the `Lift` engine (in-process) and the HTTP/MCP server, and mirrors the
/// queue, resources, models and settings for the views. Every action goes through a `Lift` command.
@MainActor @Observable
public final class AppModel {
    public enum Phase: Equatable {
        case loading, setup, ready
        case failed(String)
    }

    public private(set) var phase = Phase.loading
    public private(set) var lift: Lift?
    public private(set) var server: LiftServer?
    public private(set) var serverStatus: ServerStatus?
    public private(set) var queue: QueueStatus?
    public private(set) var resources: ResourcesView?
    public private(set) var models: [ModelView] = []
    public private(set) var settings = Settings()
    /// Jobs found interrupted at launch, until resolved or put off (spec §7).
    public var interrupted: [JobView] = []
    /// The most recent job that finished while the app was watching (menu bar "Just finished").
    public private(set) var lastFinished: JobView?
    public var confirmation: Confirmation?
    public var alert: String?
    public var section = AppSection.generate
    public let generate = GenerateModel()

    /// Called with each finished job and each new memory wait (the app posts notifications).
    public var onEvent: (@MainActor (JobEvent) -> Void)?
    /// Applies `launch_at_login` to the system (ServiceManagement in the app; a fake in tests).
    public var applyLaunchAtLogin: (@MainActor (Bool) throws -> Void)?
    public var launchAtLoginEnabled: (@MainActor () -> Bool)?

    let defaults: any PreferenceStore
    let paths: AppPaths
    let secrets: any SecretStore
    let serverPort: Int?
    var refresher: Task<Void, Never>?
    var seen: [String: JobView] = [:]

    static let workdirKey = "workdir"
    static let setupKey = "setupDone"

    /// `serverPort`: nil uses the `port` setting; 0 picks any free port (tests).
    public init(defaults: any PreferenceStore = UserDefaults.standard, paths: AppPaths = .main, secrets: any SecretStore = KeychainSecretStore(),
                serverPort: Int? = nil) {
        self.defaults = defaults
        self.paths = paths
        self.secrets = secrets
        self.serverPort = serverPort
    }

    /// The open engine, for actions; throws when Lift isn't open (the views only offer actions when it is).
    public var engine: Lift {
        get throws {
            guard let lift else { throw LiftError.invalidState("Lift isn't open") }
            return lift
        }
    }

    public var liveServer: LiftServer {
        get throws {
            guard let server else { throw LiftError.invalidState("the server isn't running") }
            return server
        }
    }

    public var workdir: URL? {
        defaults.string(forKey: Self.workdirKey).map { URL(filePath: $0) }
    }

    /// At launch: open the saved workdir, or show the first-launch wizard (spec §11) until it's finished.
    public func start() async {
        if let workdir, defaults.bool(forKey: Self.setupKey) { await open(workdir) } else { phase = .setup }
    }

    /// Back to the wizard, e.g. after the workdir failed to open.
    public func restartSetup() {
        defaults.set(false, forKey: Self.setupKey)
        phase = .setup
    }

    /// The wizard's last step.
    public func finishSetup() {
        defaults.set(true, forKey: Self.setupKey)
        phase = .ready
    }

    /// Opens (creating if needed) the workdir, starts the server, and loads interrupted jobs.
    /// `ready: false` keeps the wizard on screen (it opens Lift halfway through).
    @discardableResult
    public func open(_ workdir: URL, ready: Bool = true) async -> Bool {
        if lift != nil { await close() }
        do {
            let runtime = try installRuntime(in: workdir)
            let lift = try await Lift.open(LiftConfig(workdir: workdir, workerRuntime: runtime, bundledRecipes: paths.bundledRecipes,
                                                      secrets: secrets))
            let server = LiftServer(lift: lift, configuration: .init(port: serverPort, bridgePath: paths.bridge?.path))
            self.lift = lift
            self.server = server
            if self.workdir != workdir { defaults.set(workdir.path, forKey: Self.workdirKey) }
            do {
                serverStatus = try await server.start()
            } catch {
                self.server = nil  // the badge and Settings then say it isn't running
                alert = "The HTTP/MCP server didn't start: \(Format.error(error))"
            }
            interrupted = try await lift.jobsListInterrupted()
            await refresh()
            if ready { phase = .ready }
            refresher = Task { [weak self] in
                while !Task.isCancelled {
                    try? await Task.sleep(for: .seconds(1))
                    await self?.refresh()
                }
            }
            return true
        } catch {
            if ready { phase = .failed(Format.error(error)) } else { alert = Format.error(error) }
            return false
        }
    }

    /// Copies the bundled `lift_worker` to `<workdir>/runtime/`, so Python's bytecode cache never
    /// writes into the signed app bundle. Replaced on every launch (it's a few files).
    func installRuntime(in workdir: URL) throws -> URL {
        let fm = FileManager.default
        let runtime = workdir.appending(path: "runtime")
        let dest = runtime.appending(path: "lift_worker")
        try fm.createDirectory(at: runtime, withIntermediateDirectories: true)
        if fm.fileExists(atPath: dest.path) { try fm.removeItem(at: dest) }
        try fm.copyItem(at: paths.workerSource.appending(path: "lift_worker"), to: dest)
        return runtime
    }

    public func close() async {
        refresher?.cancel()
        refresher = nil
        await server?.stop()
        await lift?.close()
        server = nil
        lift = nil
    }

    // MARK: mirror

    public func refresh() async {
        guard let lift else { return }
        do {
            let queue = try await lift.queueStatus()
            let resources = try await lift.resourcesGet()
            let models = try await lift.modelsList()
            let settings = await lift.settingsGet()
            let status = await server?.status()
            await report(queue.jobs, lift: lift)
            // Assign only changes: every assignment re-renders the views that read it.
            if self.queue != queue { self.queue = queue }
            if self.resources != resources { self.resources = resources }
            if self.models != models { self.models = models; generate.models = models }
            if self.settings != settings { self.settings = settings }
            if serverStatus != status { serverStatus = status }
            reconcileLaunchAtLogin()
        } catch {
            if alert == nil { alert = Format.error(error) }  // once, not every second
        }
    }

    /// Finished jobs leave the queue: each one that left is fetched once, then reported with any new memory waits.
    func report(_ jobs: [JobView], lift: Lift) async {
        let ids = Set(jobs.map(\.job.id))
        var left: [JobView] = []
        for id in seen.keys where !ids.contains(id) {
            if let v = try? await lift.jobsGet(id) { left.append(v) }
        }
        for event in Self.events(previous: seen, current: jobs, left: left) {
            if case .finished(let v) = event { lastFinished = v }
            onEvent?(event)
        }
        seen = Dictionary(uniqueKeysWithValues: jobs.map { ($0.job.id, $0) })
    }

    /// What to notify: jobs that left the queue succeeded or failed (not cancelled), and jobs that just
    /// started waiting for memory.
    static func events(previous: [String: JobView], current: [JobView], left: [JobView]) -> [JobEvent] {
        func memoryWait(_ v: JobView?) -> Bool {
            if case .memory = v?.job.waitReason { true } else { false }
        }
        let waits = current.filter { memoryWait($0) && !memoryWait(previous[$0.job.id]) }.map(JobEvent.waitingForMemory)
        let done = left.filter { $0.job.state == .succeeded || $0.job.state == .failed }.map(JobEvent.finished)
        return waits + done
    }

    func reconcileLaunchAtLogin() {
        guard let apply = applyLaunchAtLogin, let enabled = launchAtLoginEnabled, settings.launchAtLogin != enabled() else { return }
        do {
            try apply(settings.launchAtLogin)
        } catch {
            alert = "Launch at login: \(Format.error(error))"
            let actual = enabled()
            run { _ = try await self.lift?.settingsSet("launch_at_login", .bool(actual)) }
        }
    }

    // MARK: actions

    /// Runs a command, showing any error in an alert, then refreshes.
    public func run(_ body: @escaping @MainActor () async throws -> Void) {
        Task {
            do { try await body() } catch { alert = Format.error(error) }
            await refresh()
        }
    }

    /// Runs a confirm-gated command: without confirmation first, and if it answers
    /// `confirmationRequired`, shows the impact and runs it again with `confirm: true` on OK.
    public func gated<T: Sendable>(_ call: @escaping @MainActor (_ confirm: Bool) async throws -> Gated<T>,
                                   then done: @escaping @MainActor (T) -> Void = { _ in }) {
        run {
            switch try await call(false) {
            case .done(let value): done(value)
            case .confirmationRequired(let impact):
                self.confirmation = Confirmation(message: impact) { [weak self] in
                    self?.run { if let value = try await call(true).value { done(value) } }
                }
            }
        }
    }

    /// Queues the Generate form: one job per input file. Bad input (per field) stays in the form.
    public func submitGenerate() {
        let requests = generate.requests
        run {
            guard let lift = self.lift else { return }
            self.generate.errors = []
            for request in requests {
                do {
                    _ = try await lift.jobsSubmit(request)
                } catch LiftError.invalidInput(let errors) {
                    self.generate.errors = errors
                    return
                }
            }
            self.generate.files = []
            self.generate.text = ""
        }
    }

    public func resolveInterrupted(_ action: InterruptedAction) {
        let ids = interrupted.map(\.job.id)
        interrupted = []
        run { _ = try await self.lift?.jobsResolveInterrupted(ids: ids, action: action) }
    }

    /// The end of a job's log (`<workdir>/jobs/<id>/log.txt`).
    public func logTail(_ job: String, maxBytes: Int = 16_384) -> String {
        guard let workdir, let handle = try? FileHandle(forReadingFrom: workdir.appending(path: "jobs/\(job)/log.txt")) else { return "" }
        defer { try? handle.close() }
        let size = (try? handle.seekToEnd()) ?? 0
        try? handle.seek(toOffset: size > UInt64(maxBytes) ? size - UInt64(maxBytes) : 0)
        return String(decoding: (try? handle.readToEnd()) ?? Data(), as: UTF8.self)
    }

    /// Moves the working directory (database, recipes, models, jobs) and reopens Lift there.
    /// Needs confirmation; workers stop and running jobs come back as interrupted.
    public func moveWorkdir(to destination: URL) {
        guard let from = workdir else { return }
        let message = "Moves Lift's working directory from \(from.path) to \(destination.path). Workers stop, "
            + "running jobs come back as interrupted, and the HTTP/MCP server restarts. Installed models may need Reinstall "
            + "if their environment has absolute paths."
        confirmation = Confirmation(message: message) { [weak self] in
            guard let self else { return }
            await self.close()
            do {
                try FileManager.default.moveItem(at: from, to: destination)
                await self.open(destination)
            } catch {
                self.alert = Format.error(error)
                await self.open(from)
            }
        }
    }
}

/// Turns a list drag (`onMove` indices) into a `jobs_move` target; nil when the job stays put.
enum QueueOrder {
    static func target(_ ids: [String], from: Int, to: Int) -> MoveTarget? {
        guard ids.indices.contains(from), to != from, to != from + 1 else { return nil }
        return to < ids.count ? .before(ids[to]) : .after(ids[ids.count - 1])
    }
}

import Foundation
import LiftCore
import Observation

public enum HistoryFilter: Hashable, Sendable, CaseIterable {
    case all, modality3d, image, video, audio, rigged, failed

    public var label: String {
        switch self {
        case .all: "All"
        case .modality3d: "3D"
        case .image: "Image"
        case .video: "Video"
        case .audio: "Audio"
        case .rigged: "Rigged"
        case .failed: "Failed"
        }
    }
}

/// History: finished jobs (kept until you delete them, spec §7), filtered by modality, output type or
/// failure, plus a title search.
@MainActor @Observable
public final class HistoryModel {
    public var filter = HistoryFilter.all
    public var text = ""
    public var selected: String?
    public private(set) var jobs: [JobView] = []

    public init() {}

    public var current: JobView? { jobs.first { $0.job.id == selected } }

    /// The LiftCore query for the filter; `rigged` is narrowed afterwards by output type.
    var query: JobFilter {
        let finished: [JobState] = [.succeeded, .failed, .cancelled]
        let text = text.isEmpty ? nil : text
        switch filter {
        case .all, .rigged: return JobFilter(states: finished, text: text)
        case .modality3d: return JobFilter(states: finished, modality: "3d", text: text)
        case .image: return JobFilter(states: finished, modality: "image", text: text)
        case .video: return JobFilter(states: finished, modality: "video", text: text)
        case .audio: return JobFilter(states: finished, modality: "audio", text: text)
        case .failed: return JobFilter(states: [.failed], text: text)
        }
    }

    public func reload(_ lift: Lift, models: [ModelView]) async throws {
        var found = try await lift.jobsList(query)
        if filter == .rigged { found = found.filter { Self.output(of: $0, models: models) == .riggedMesh } }
        if found != jobs { jobs = found }
        if selected == nil || current == nil { selected = jobs.first?.job.id }
    }

    /// The type the job's last step produces, from its recipe task.
    public static func output(of v: JobView, models: [ModelView]) -> IOType? {
        guard let last = v.steps.last else { return nil }
        return models.first { $0.id == last.recipe }?.recipe.task(last.task)?.output
    }

    /// `curl` that submits the same job again over HTTP (spec §10): the same steps, inputs (the job's
    /// copies) and settings. A chained step's first input comes from the step before, so it's left out.
    public static func curl(_ v: JobView, apiBase: String, models: [ModelView]) -> String {
        let steps: [[String: Any]] = v.steps.map { s in
            var inputs = s.inputs
            if s.idx > 0, let first = models.first(where: { $0.id == s.recipe })?.recipe.task(s.task)?.inputs.first {
                inputs[first.name] = nil
            }
            let settings = (try? JSONSerialization.jsonObject(with: JSONEncoder().encode(s.settings))) ?? [:]
            return ["recipe": s.recipe, "task": s.task, "inputs": inputs, "settings": settings]
        }
        let body: [String: Any] = ["steps": steps, "title": v.job.title, "priority": v.job.priority.rawValue]
        let json = (try? JSONSerialization.data(withJSONObject: body, options: [.sortedKeys, .withoutEscapingSlashes]))
            .map { String(decoding: $0, as: UTF8.self) } ?? "{}"
        return "curl -X POST \(apiBase)/jobs -H 'Content-Type: application/json' -d '\(json.replacingOccurrences(of: "'", with: "'\\''"))'"
    }
}

/// Which viewer shows an output file (mockup Viewers.dc.html). Decided by the file's extension.
public enum ViewerKind: Equatable, Sendable {
    case mesh, image, video, audio, none

    public static func of(_ path: String) -> ViewerKind {

        case "glb", "gltf", "obj", "usdz", "usd", "usdc": .mesh
        case "png", "jpg", "jpeg", "webp", "heic", "tiff": .image
        case "mp4", "mov", "m4v": .video

enum MeshMode: String, CaseIterable {

/// 3D preview: glTF through GLTFKit2 into SceneKit; OBJ and USDZ through SceneKit (ModelIO).
/// Drag to orbit, scroll to zoom.
struct MeshView: View {
    let url: URL
    @State private var mode = MeshMode.textured
    @State private var loaded: (scene: SCNScene, animations: [GLTFSCNAnimation])?
    @State private var error: String?
    @State private var playing = false

    var body: some View {
        ZStack(alignment: .bottom) {
            if let loaded {
                SceneKitView(scene: loaded.scene, debugOptions: mode.debugOptions)
            } else if let error {
                ContentUnavailableView("Can't show this mesh", systemImage: "cube.transparent", description: Text(error))
            } else {
                ProgressView()
            }
            HStack {
                Picker("Mode", selection: $mode) {
                    ForEach(MeshMode.allCases, id: \.self) { Text($0.rawValue).tag($0) }
                }
                .pickerStyle(.segmented)
                .labelsHidden()
                .fixedSize()
                if let animations = loaded?.animations, !animations.isEmpty {
                    Toggle("Play animation", isOn: $playing).toggleStyle(.button)
                }
            }
            .padding(8)
        }
        .background(Color(white: 0.17))
        .task(id: "\(url.path)|\(mode == .clay)") { load(clay: mode == .clay) }
        .onChange(of: playing) { play(playing) }
    }

    // ponytail: parses on the main actor; move to a background task if big meshes stall the UI.
    func load(clay: Bool) {
        do {
            let scene: SCNScene
            var animations: [GLTFSCNAnimation] = []
            if ["glb", "gltf"].contains(url.pathExtension.lowercased()) {
                let source = GLTFSCNSceneSource(asset: try GLTFAsset(url: url, options: [:]))
                scene = source.defaultScene ?? SCNScene()
                animations = source.animations
                if clay {
                    for m in source.materials { Self.makeClay(m) }
                }
            } else {
                scene = try SCNScene(url: url)
                if clay {
                    scene.rootNode.enumerateHierarchy { node, _ in node.geometry?.materials.forEach(Self.makeClay) }
                }
            }
            loaded = (scene, animations)
            playing = false
            error = nil
        } catch {
            self.error = error.localizedDescription
        }
    }

    static func makeClay(_ m: SCNMaterial) {
        m.diffuse.contents = NSColor(white: 0.75, alpha: 1)
        for p in [m.normal, m.emission, m.metalness, m.ambientOcclusion] { p.contents = nil }
        m.roughness.contents = 0.8
    }

    func play(_ on: Bool) {
        guard let loaded else { return }
        for (i, a) in loaded.animations.enumerated() {
            let key = "lift-\(i)"
            if on {
                loaded.scene.rootNode.addAnimationPlayer(a.animationPlayer, forKey: key)
                a.animationPlayer.play()
            } else {
                loaded.scene.rootNode.removeAnimation(forKey: key)
            }
        }
    }
}

struct SceneKitView: NSViewRepresentable {
    let scene: SCNScene
    let debugOptions: SCNDebugOptions

    func makeNSView(context: Context) -> SCNView {
        let view = SCNView()
        view.allowsCameraControl = true
        view.autoenablesDefaultLighting = true
        view.backgroundColor = NSColor(white: 0.17, alpha: 1)
        return view
    }

    func updateNSView(_ view: SCNView, context: Context) {
        if view.scene !== scene { view.scene = scene }
        view.debugOptions = debugOptions
    }
}

                app.gated { confirm in try await app.engine.jobsDelete(v.job.id, confirm: confirm) }
            }
        }
    }

    func copy(_ text: String) {
        NSPasteboard.general.clearContents()
        NSPasteboard.general.setString(text, forType: .string)
    }

/// Retry with new settings for the step a retry restarts from (spec §10 `jobs_retry`).
struct RetrySheet: View {
    let app: AppModel
    let job: JobView
    let done: () -> Void
    @State private var values: [String: SettingValue] = [:]
    @State private var errors: [FieldError] = []

    var step: StepRecord { job.steps.first { $0.state != .succeeded } ?? job.steps[0] }

    var body: some View {
        let task = app.models.first { $0.id == step.recipe }?.recipe.task(step.task)
        Form {
            Section("Retry \(job.job.title) from step \(step.idx + 1)") {
                SettingsForm(defs: task?.settings ?? [], values: $values) { key in
                    errors.filter { $0.field == "settings.\(key)" }.map(\.message)
                }
            }
        }
        .formStyle(.grouped)
        .frame(minWidth: 420, minHeight: 320)
        .onAppear { values = step.settings }
        .toolbar {
            ToolbarItem(placement: .cancellationAction) { Button("Cancel", action: done) }
            ToolbarItem(placement: .confirmationAction) {
                Button("Retry") {
                    Task {
                        do {
                            _ = try await app.engine.jobsRetry(job.job.id, settings: values)
                            done()
                        } catch LiftError.invalidInput(let e) {
                            errors = e
                        } catch {
                            app.alert = Format.error(error)
                        }
                    }
                }
            }
        }
    }
}

import Foundation
import LiftCore
import Observation

/// The first-launch wizard (spec §11). The working directory comes first because opening it starts the
/// engine, which runs the toolchain checks and installs, copies the bundled recipes and stores the token.
@MainActor @Observable
public final class SetupModel {
    public enum Step: Int, CaseIterable, Sendable {
        case folders, toolchain, recipes, huggingFace, mcp

        public var title: String {
            switch self {
            case .folders: "Working directory"
            case .toolchain: "Toolchain"
            case .recipes: "Recipes"
            case .huggingFace: "Hugging Face"
            case .mcp: "Connect an MCP client"
            }
        }
    }

    public var step = Step.folders
    public var workdir: URL
    public private(set) var prereqs: Prereqs?
    public private(set) var log: [String] = []
    public private(set) var recipes: RecipeSourcesView?
    public var hfToken = ""
    public private(set) var busy = false

    public init(workdir: URL? = nil) {
        self.workdir = workdir ?? FileManager.default.urls(for: .applicationSupportDirectory, in: .userDomainMask)[0].appending(path: "Lift")
    }

    public var missingTools: Bool {
        guard let t = prereqs?.tools else { return true }
        return t.brew == nil || t.git == nil || t.uv == nil
    }

    /// Moves to the next step, doing that step's work first.
    public func next(_ app: AppModel) async {
        busy = true
        defer { busy = false }
        switch step {
        case .folders:
            guard await app.open(workdir, ready: false) else { return }
            await checkTools(app)
            step = .toolchain
        case .toolchain:
            recipes = await app.lift?.recipesListSources()
            step = .recipes
        case .recipes:
            step = .huggingFace
        case .huggingFace:
            if !hfToken.isEmpty {
                do { _ = try await app.engine.secretsSetHFToken(hfToken) } catch { app.alert = Format.error(error); return }
                hfToken = ""
            }
            step = .mcp
        case .mcp:
            app.finishSetup()
        }
    }

    public func checkTools(_ app: AppModel) async {
        prereqs = await app.lift?.systemPrereqs()
    }

    /// Installs missing tools (native Homebrew via one administrator dialog, then git and uv) with a live log.
    public func installTools(_ app: AppModel) {
        log = []
        let onLine: @Sendable (String) -> Void = { line in Task { @MainActor [weak self] in self?.log.append(line) } }
        app.gated { confirm in try await app.engine.systemInstallPrereqs(confirm: confirm, onLine: onLine) } then: { [weak self] in self?.prereqs = $0 }
    }
}

import AppKit
import LiftCore
@preconcurrency import UserNotifications

/// macOS notifications for job events (spec §8, §11), with a Reveal in Finder action.
/// Needs a real app bundle: UNUserNotificationCenter isn't available to bare executables or test runners.
@MainActor
public final class Notifier: NSObject, UNUserNotificationCenterDelegate {
    nonisolated static let reveal = "reveal"
    nonisolated static let category = "job"

    public override init() {
        super.init()
        let center = UNUserNotificationCenter.current()
        center.delegate = self
        let action = UNNotificationAction(identifier: Self.reveal, title: "Reveal in Finder")
        center.setNotificationCategories([UNNotificationCategory(identifier: Self.category, actions: [action], intentIdentifiers: [])])
        center.requestAuthorization(options: [.alert, .sound]) { _, _ in }
    }

    public func post(_ event: JobEvent) {
        let content = Self.content(event)
        UNUserNotificationCenter.current().add(UNNotificationRequest(identifier: UUID().uuidString, content: content, trigger: nil))
    }

    /// The text of each notification; facts only.
    static func content(_ event: JobEvent) -> UNMutableNotificationContent {
        let c = UNMutableNotificationContent()
        c.categoryIdentifier = category
        switch event {
        case .finished(let v):
            c.title = v.job.state == .succeeded ? "Finished: \(v.job.title)" : "Failed: \(v.job.title)"
            c.body = v.job.state == .succeeded ? v.outputs.map { URL(filePath: $0).lastPathComponent }.joined(separator: ", ") : (v.job.error ?? "")
            if let path = v.outputs.first { c.userInfo = ["path": path] }
        case .waitingForMemory(let v):
            c.title = "Waiting for memory: \(v.job.title)"
            c.body = Format.waitReason(v.job.waitReason)
        }
        return c
    }

    public nonisolated func userNotificationCenter(_ center: UNUserNotificationCenter, didReceive response: UNNotificationResponse) async {
        guard response.actionIdentifier == Self.reveal, let path = response.notification.request.content.userInfo["path"] as? String else { return }
        await MainActor.run { NSWorkspace.shared.activateFileViewerSelecting([URL(filePath: path)]) }
    }

    public nonisolated func userNotificationCenter(_ center: UNUserNotificationCenter, willPresent notification: UNNotification) async -> UNNotificationPresentationOptions {
        [.banner, .sound]
    }
}

#!/bin/sh
# Launch smoke test (spec §14): runs the built app on a throwaway working directory and passes once
# the sidebar is on screen. Nothing is written outside the temp folder: the workdir and the setup flag
# come in on the command line (UserDefaults reads them without saving), and CFFIXED_USER_HOME sends
# AppKit's own preference writes (window and split-view frames) to the temp folder.
# Usage: App/smoke-test.sh path/to/Lift.app
set -eu
app="$1"
tmp="$(mktemp -d)"
mkdir -p "$tmp/home"
CFFIXED_USER_HOME="$tmp/home" "$app/Contents/MacOS/Lift" -LiftSmokeTest YES -workdir "$tmp/workdir" -setupDone YES \
    -ApplePersistenceIgnoreState YES > "$tmp/smoke.log" 2>&1 &
pid=$!
n=0
while kill -0 "$pid" 2>/dev/null && [ "$n" -lt 90 ]; do sleep 1; n=$((n + 1)); done
if kill -0 "$pid" 2>/dev/null; then
    kill "$pid"
    echo "FAIL: Lift was still running after 90 s"; cat "$tmp/smoke.log"; exit 1
fi
wait "$pid" || { echo "FAIL: Lift exited with $?"; cat "$tmp/smoke.log"; exit 1; }
if grep -q "LIFT_SMOKE sidebar: Generate, Queue, History, Models, Settings" "$tmp/smoke.log"; then
    echo "PASS: $(grep LIFT_SMOKE "$tmp/smoke.log")"
    echo "temp folder: $tmp"
else
    echo "FAIL: no sidebar line"; cat "$tmp/smoke.log"; exit 1
fi
